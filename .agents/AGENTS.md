# Project Rules

<!-- AUTO-COMMIT AND PUSH RULE -->
> [!IMPORTANT]
> This project is connected to Lovable, and the user prefers to have all changes synced immediately.
> After completing ANY feature, bug fix, or user request, you MUST automatically run `git add .`, `git commit -m "..."`, and `git push` without waiting for the user to explicitly ask for it. Always keep the Lovable platform synced with your local changes.
